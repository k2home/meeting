Vollständiger Datenbank-Export und -Import

Erstellt eine vollständige PostgreSQL-Sicherung mit allen Datenbanktabellen, Benutzerkonten, Besprechungen, Protokollen und gespeicherten Organisationseinstellungen. Die Datei enthält zusätzlich den angewendeten Django-Migrationsstand. Beim Import werden fehlende Migrationen automatisch in der richtigen Reihenfolge ausgeführt. Backups aus einer neueren oder inkompatiblen Programmversion werden abgewiesen.

Achtung: Der Import ersetzt die vorhandenen Datenbankinhalte. Die Sicherung enthält den Django-Migrationsstand. Fehlende Migrationen werden nach dem Wiederherstellen automatisch ausgeführt. Backups aus einer neueren Programmversion werden nicht importiert. Vor dem Import wird automatisch eine Sicherung des aktuellen Datenstands erstellt. Bei einem fehlgeschlagenen Restore oder einer fehlgeschlagenen Migration wird diese Sicherung automatisch wiederhergestellt. Nach erfolgreichem Import wirst du abgemeldet.
